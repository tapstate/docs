## Current preview

The public preview demonstrates one concrete operational data path:

- MySQL orders and PostgreSQL shipments, each captured by an initial load plus
  continuous change data capture (CDC)
- an in-flight `nest` transform that assembles one order document
- continuous materialization to MongoDB

The local MongoDB instance is the preview's managed state store for the
declared view.
Do not infer another store, query API, or push surface from the broader product
model. Start with the [Quickstart](/docs/overview/quickstart) to
run the current path locally.

The server-backed preview is supplied through the disposable Docker playground;
this release does not publish a standalone server installer.
